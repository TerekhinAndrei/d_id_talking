## 🚀 Как внести свой вклад

### 1. Подготовка к разработке

1. **Форкните репозиторий**
2. **Клонируйте ваш форк**
   ```bash
   git clone https://github.com/YOUR_USERNAME/d_id_talking.git
   cd d_id_talking
   ```

3. **Настройте окружение**
   ```bash
   # Backend
   pip install -r requirements.txt
   
   # Frontend
   cd frontend
   npm install
   ```

### 2. Создание ветки

Используйте наши скрипты для создания веток:

```bash
# Для новой функции
./scripts/create-branch.sh feature "название-функции"

# Для исправления бага
./scripts/create-branch.sh bugfix "описание-бага"

# Для срочного исправления
./scripts/create-branch.sh hotfix "срочное-исправление"
```

### 3. Разработка

#### Backend разработка
- Следуйте руководству [BACKEND_GUIDE.md](BACKEND_GUIDE.md)
- Используйте FastAPI для новых endpoints
- Добавляйте тесты для новых функций
- Документируйте API изменения

#### Frontend разработка
- Следуйте руководству [FRONTEND_GUIDE.md](FRONTEND_GUIDE.md)
- Используйте React 18 и современные хуки
- Следуйте принципам компонентной архитектуры
- Добавляйте тесты для компонентов

### 4. Коммиты

Используйте конвенциональные коммиты:

```bash
# Новые функции
git commit -m "feat: добавить новую функцию"

# Исправления багов
git commit -m "fix: исправить проблему с микрофоном"

# Документация
git commit -m "docs: обновить README"

# Рефакторинг
git commit -m "refactor: оптимизировать код"

# Тесты
git commit -m "test: добавить тесты для компонента"
```

### 5. Завершение работы

Используйте наши скрипты для завершения работы:

```bash
# Завершение feature ветки
./scripts/merge-branch.sh feature "название-функции"

# Завершение bugfix ветки
./scripts/merge-branch.sh bugfix "описание-бага"
```

### 6. Pull Request

1. **Создайте Pull Request** в основной репозиторий
2. **Опишите изменения** в описании PR
3. **Укажите связанные issues** если есть
4. **Дождитесь code review** от авторов

## 📋 Требования к коду

### Backend (Python/FastAPI)
- ✅ Следуйте PEP 8
- ✅ Добавляйте типизацию
- ✅ Покрывайте код тестами
- ✅ Документируйте функции
- ✅ Обрабатывайте ошибки

### Frontend (React/TypeScript)
- ✅ Используйте TypeScript
- ✅ Следуйте ESLint правилам
- ✅ Компоненты должны быть переиспользуемыми
- ✅ Добавляйте PropTypes или TypeScript интерфейсы
- ✅ Тестируйте компоненты

### Общие требования
- ✅ Пишите понятный код
- ✅ Добавляйте комментарии где необходимо
- ✅ Обновляйте документацию
- ✅ Не ломайте существующую функциональность

## 🧪 Тестирование

### Backend тесты
```bash
# Запуск всех тестов
python -m pytest tests/

# Запуск с покрытием
python -m pytest --cov=app tests/

# Запуск конкретного теста
python -m pytest tests/test_d_id_service.py
```

### Frontend тесты
```bash
cd frontend

# Запуск всех тестов
npm test

# Запуск с покрытием
npm run test:coverage

# Запуск в режиме watch
npm run test:watch
```
