# Анализ замены модуля распознавания речи на @ricky0123/vad-web

## 🔍 Текущая реализация

### Текущий алгоритм детекции речи:
```javascript
detectSpeech(audioData) {
  const volume = Math.sqrt(
    audioData.reduce((sum, sample) => sum + sample * sample, 0) / audioData.length
  );
  return volume > this.speechThreshold;
}
```

**Характеристики:**
- ✅ Простая реализация на основе RMS (Root Mean Square)
- ✅ Низкое потребление ресурсов
- ✅ Работает в AudioWorklet (отдельный поток)
- ❌ Высокая частота ложных срабатываний
- ❌ Не различает речь от шума
- ❌ Фиксированный порог чувствительности

## 📊 Анализ библиотеки @ricky0123/vad-web

- **Версия:** 0.0.24 (последняя)

- ✅ **Множественные события:** `onSpeechStart`, `onSpeechEnd`, `onVADMisfire`
- ✅ **Настраиваемые параметры:** Чувствительность, время тишины, частота дискретизации
- ✅ **Офлайн работа:** Не требует интернета после загрузки модели

## 🎯 Оценка возможности замены

### ✅ Преимущества замены:

#### 1. **Качество детекции**
```javascript
// Текущая реализация - много ложных срабатываний
const hasSpeech = volume > 0.01; // Простой порог

// @ricky0123/vad-web - точная детекция
const vad = await vad.MicVAD.new({
  onSpeechStart: () => console.log('Речь началась'),
  onSpeechEnd: (audio) => {
    // audio содержит только чистую речь
    sendToElevenLabs(audio);
  },
  onVADMisfire: () => console.log('Ложное срабатывание')
});
```

#### 2. **Улучшенная архитектура**
```javascript
// Текущий подход - ручная обработка
if (hasSpeech) {
  audioBuffer.push(audioData);
} else if (isSpeaking) {
  // Сложная логика определения конца речи
}

// Новый подход - событийная модель
vad.onSpeechStart = () => {
  // Начало речи
};

vad.onSpeechEnd = (audio) => {
  // Готовая фраза для отправки
  sendPhraseToElevenLabs(audio);
};
```

#### 3. **Настраиваемые параметры**
```javascript
const vad = await vad.MicVAD.new({
  // Чувствительность (0-1)
  sensitivity: 0.5,
  
  // Минимальная длительность речи (мс)

  // Максимальная длительность речи (мс)
  maxSpeechFrames: 60,
  
  // Время тишины для определения конца речи (мс)
  silenceFrames: 8,
  
  // Частота дискретизации

});
```

### Этап 2: Создание нового хука
```javascript
// hooks/useVadStreaming.js
import { MicVAD } from '@ricky0123/vad-web';

export const useVadStreaming = (options = {}) => {
  const [isRecording, setIsRecording] = useState(false);
  const [vadInstance, setVadInstance] = useState(null);
  
  const startRecording = useCallback(async (voiceId) => {
    try {
      const vad = await MicVAD.new({
        onSpeechStart: () => {
          console.log('🎤 Речь началась');
        },
        onSpeechEnd: (audio) => {
          console.log('🎤 Речь закончилась, отправляем в ElevenLabs');
          sendToElevenLabs(audio, voiceId);
        },
        onVADMisfire: () => {
          console.log('⚠️ Ложное срабатывание VAD');
        },
        sensitivity: 0.5,
        minSpeechFrames: 3,
        maxSpeechFrames: 60,
        silenceFrames: 8,
        sampleRate: 16000
      });
      
      setVadInstance(vad);
      await vad.start();
      setIsRecording(true);
      
    } catch (error) {
      console.error('Ошибка запуска VAD:', error);
    }
  }, []);
  
  const stopRecording = useCallback(() => {
    if (vadInstance) {
      vadInstance.destroy();
      setVadInstance(null);
      setIsRecording(false);
    }
  }, [vadInstance]);
  
  return { isRecording, startRecording, stopRecording };
};
```
