# Отчет о внешних запросах к сторонним серверам

## Обзор

Данный отчет содержит полную информацию о всех внешних API запросах, которые выполняет приложение к сторонним серверам. Проект интегрирован с тремя основными внешними сервисами.

---

## 1. ElevenLabs API

### Конфигурация
- **Базовый URL**: `https://api.elevenlabs.io/v1`
- **Аутентификация**: API Key в заголовке `xi-api-key`
- **Сервис**: `app/services/elevenlabs_service.py`

### Запросы

#### 1.1 Получение списка голосов
- **Метод**: `GET`
- **Эндпоинт**: `/voices`
- **Описание**: Получение списка доступных голосов для синтеза речи
- **Использование**: Проверка аутентификации, валидация voice_id
- **Файл**: `app/services/elevenlabs_service.py:get_available_voices()`

#### 1.2 Получение голоса по ID
- **Метод**: `GET`
- **Эндпоинт**: `/voices/{voice_id}`
- **Описание**: Получение детальной информации о конкретном голосе
- **Использование**: Валидация и получение информации о голосе
- **Файл**: `app/services/elevenlabs_service.py:get_voice_by_id()`

#### 1.3 Speech-to-Speech преобразование
- **Метод**: `POST`
- **Эндпоинт**: `/speech-to-speech/{voice_id}`
- **Описание**: Преобразование аудио в аудио с изменением голоса
- **Формат данных**: `multipart/form-data`
- **Параметры**:
  - `audio`: аудио файл (WAV/MP3)
  - `model_id`: модель для обработки
  - `voice_settings`: настройки голоса
- **Использование**: Основная функция обработки аудио
- **Файл**: `app/services/elevenlabs_service.py:speech_to_speech()`

#### 1.4 Text-to-Speech преобразование
- **Метод**: `POST`
- **Эндпоинт**: `/text-to-speech/{voice_id}`
- **Описание**: Преобразование текста в речь
- **Формат данных**: `application/json`
- **Параметры**:
  - `text`: текст для синтеза
  - `model_id`: модель для синтеза
  - `voice_settings`: настройки голоса
- **Использование**: Fallback при недоступности Speech-to-Speech
- **Файл**: `app/services/elevenlabs_service.py:text_to_speech()`

#### 1.5 Speech-to-Speech с URL
- **Метод**: `POST`
- **Эндпоинт**: `/speech-to-speech/{voice_id}`
- **Описание**: Обработка аудио по URL с последующим преобразованием
- **Дополнительно**: Сначала загружает аудио по URL, затем обрабатывает
- **Файл**: `app/services/elevenlabs_service.py:speech_to_speech_with_url()`

- **Сервис**: `app/services/d_id_service.py`

### Запросы

- **Метод**: `GET`
- **Эндпоинт**: `/talks`

- **Использование**: Тестирование аутентификации, мониторинг

#### 2.2 Получение talk по ID

  - `config`: настройки видео
- **Использование**: Создание видео с текстом
- **Файл**: `app/services/d_id_service.py:create_talk_with_text()`

#### 2.4 Создание talk с аудио
- **Метод**: `POST`
- **Эндпоинт**: `/talks`
- **Описание**: Создание видео с аудио скриптом
- **Формат данных**: `application/json`
- **Параметры**:
  - `source_url`: URL изображения
  - `script`: аудио скрипт
  - `config`: настройки видео
- **Использование**: Создание видео с готовым аудио
- **Файл**: `app/services/d_id_service.py:create_talk_with_audio()`

## 3. Cloudinary API

### Конфигурация
- **Базовый URL**: Определяется в `CLOUDINARY_URL`
- **Аутентификация**: Через URL с credentials
- **Сервис**: `app/services/storage_service.py`

### Запросы

#### 3.1 Загрузка изображения
- **Метод**: `POST` (через SDK)
- **Эндпоинт**: Cloudinary Upload API
- **Описание**: Загрузка изображения в облачное хранилище
- **Параметры**:
  - `file_data`: байты изображения
  - `public_id`: путь к файлу
  - `resource_type`: "image"
- **Использование**: Сохранение загруженных изображений
- **Файл**: `app/services/storage_service.py:upload_image()`

#### 3.2 Загрузка аудио
- **Метод**: `POST` (через SDK)
- **Эндпоинт**: Cloudinary Upload API
- **Описание**: Загрузка аудио файла в облачное хранилище
- **Параметры**:
  - `file_data`: байты аудио
  - `public_id`: путь к файлу
  - `resource_type`: "video" (для аудио)
- **Использование**: Сохранение обработанных аудио файлов
- **Файл**: `app/services/storage_service.py:upload_audio()`

#### 3.3 Получение информации о файле
- **Метод**: `GET` (через SDK)
- **Эндпоинт**: Cloudinary API
- **Описание**: Получение информации о загруженном файле
- **Использование**: Получение публичного URL файла
- **Файл**: `app/services/storage_service.py:get_public_url()`

#### 3.4 Удаление файла
- **Метод**: `DELETE` (через SDK)
- **Эндпоинт**: Cloudinary API
- **Описание**: Удаление файла из облачного хранилища
- **Использование**: Очистка временных файлов
- **Файл**: `app/services/storage_service.py:delete_file()`

#### 3.5 Получение списка файлов
- **Метод**: `GET` (через SDK)
- **Эндпоинт**: Cloudinary API
- **Описание**: Получение списка файлов в папке
- **Использование**: Мониторинг и управление файлами
- **Файл**: `app/services/storage_service.py:list_files()`

#### 3.6 Тест подключения
- **Метод**: `GET` (через SDK)
- **Эндпоинт**: Cloudinary Ping API
- **Описание**: Проверка доступности Cloudinary
- **Использование**: Валидация конфигурации
- **Файл**: `app/services/storage_service.py:test_connection()`

## 6. Обработка ошибок

### ElevenLabs
- **401**: Неверный API ключ
- **400**: Неверные параметры запроса
- **422**: Ошибка валидации
- **Fallback**: Переключение на Text-to-Speech при недоступности Speech-to-Speech

### D-ID
- **401**: Неверная аутентификация
- **400**: Неверные параметры запроса
- **500**: Внутренняя ошибка сервера
- **Fallback**: Создание демо-talk при недоступности API

### Cloudinary
- **401**: Неверные credentials
- **404**: Файл не найден
- **413**: Файл слишком большой
- **Fallback**: Локальное хранение при недоступности

## 7. Таймауты и лимиты

### ElevenLabs
- **Таймаут запросов**: 60 секунд
- **Максимальный размер аудио**: Зависит от плана
- **Лимит запросов**: Зависит от плана

### D-ID
- **Таймаут запросов**: 60 секунд
- **Время генерации видео**: 30-120 секунд
- **Лимит запросов**: Зависит от плана

### Cloudinary
- **Таймаут загрузки**: 60 секунд
- **Максимальный размер файла**: 100MB
- **Лимит запросов**: Зависит от плана

## 8. Безопасность

### Аутентификация
- **ElevenLabs**: API Key в заголовке `xi-api-key`
- **D-ID**: Basic Auth с API key
- **Cloudinary**: Credentials в URL

### Передача данных
- **HTTPS**: Все внешние запросы используют HTTPS
- **Валидация**: Проверка входных данных перед отправкой
- **Логирование**: Логирование всех внешних запросов

---

## 9. Мониторинг и логирование

### Логирование запросов
- Все внешние запросы логируются с уровнем INFO
- Ошибки логируются с уровнем ERROR
- Включается информация о статусе, размере данных, времени выполнения

### Метрики
- Время выполнения запросов
- Количество успешных/неуспешных запросов
- Размер передаваемых данных
