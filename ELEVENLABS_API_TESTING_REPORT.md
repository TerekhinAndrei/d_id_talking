## 🔧 Исправленные проблемы

### 1. Обработка бинарных данных

**Проблема:** HTTP клиент пытался декодировать бинарные аудио данные как UTF-8 текст

**Решение:** Обновлен метод `_handle_response` в `app/core/base.py`
```python
# Проверка content-type для определения типа данных
content_type = response.headers.get('content-type', '')

# Если это аудио данные, возвращаем бинарный контент
if 'audio' in content_type or 'application/octet-stream' in content_type:
    return await response.read()
```
