# Детальная архитектура системы D-ID Talking

## Обзор системы

Система представляет собой полнофункциональное веб-приложение для создания анимированных видео с использованием ElevenLabs для обработки аудио и D-ID для генерации видео. Архитектура построена на FastAPI (backend) и React (frontend) с интеграцией облачных API.

## Архитектурные компоненты

### 1. Backend (FastAPI)

#### Основные модули:
- **`app/main.py`** - Точка входа FastAPI приложения
- **`app/config.py`** - Централизованная конфигурация с поддержкой .env
- **`app/api/v1/endpoints/`** - REST API эндпоинты
- **`app/services/`** - Бизнес-логика и интеграции с внешними API
- **`app/models/`** - Pydantic модели данных

#### API Endpoints:
```
GET  /api/v1/health          - Проверка состояния системы
GET  /api/v1/voices          - Получение списка голосов ElevenLabs
POST /api/v1/generate        - Создание задачи генерации видео
GET  /api/v1/status/{task_id} - Получение статуса задачи
```

### 2. Frontend (React + Vite)

#### Структура:
- **`frontend/src/App.jsx`** - Главный компонент приложения
- **`frontend/src/services/api.js`** - API клиент (Axios)
- **`frontend/src/App.css`** - Стили с современным дизайном

#### Функциональность:
- ✅ Подключение к backend API
- ✅ Получение и отображение списка голосов
- ✅ Загрузка изображений и аудио файлов
- ✅ Предварительный просмотр файлов
- ✅ Отправка запросов на генерацию видео
- ✅ Отображение прогресса и статуса задач
- ✅ Современный UI с градиентами и анимациями

### 3. Интеграции с внешними API

#### ElevenLabs API:
- **Аутентификация**: API ключ в заголовке `xi-api-key`
- **Endpoints**: 
  - `GET /voices` - получение списка голосов
  - `POST /speech-to-speech/{voice_id}` - Speech-to-Speech
  - `POST /text-to-speech/{voice_id}` - Text-to-Speech (fallback)
- **Формат запросов**: `multipart/form-data` для Speech-to-Speech
- **Обработка ошибок**: Fallback с Speech-to-Speech на Text-to-Speech

#### D-ID API:
- **Аутентификация**: `Basic API_USERNAME:API_PASSWORD`
- **Endpoints**:
  - `GET /talks` - получение списка talks
  - `POST /talks` - создание нового talk
  - `GET /talks/{talk_id}` - получение статуса talk
- **Формат запросов**: JSON с `source_url` и `script` объектом
- **Статусы**: created, started, done, failed

## Текущее состояние компонентов

### ✅ Полностью реализовано:

1. **Backend API**:
   - FastAPI приложение с CORS поддержкой
   - Централизованная конфигурация через `app/config.py`
   - Валидация файлов и данных через Pydantic
   - Background tasks для асинхронной обработки
   - Система хранения задач в памяти

2. **ElevenLabs интеграция**:
   - Полная интеграция с ElevenLabs API
   - Поддержка Speech-to-Speech и Text-to-Speech
   - Fallback механизм при ошибках
   - Обработка аудио файлов и сохранение результатов
   - Получение списка доступных голосов

3. **D-ID интеграция**:
   - Правильная аутентификация с Basic Auth
   - Создание talks с текстовыми и аудио скриптами
   - Получение статуса talks
   - Обработка статусов 200/201 для успешных запросов
   - Fallback механизмы для обработки ошибок

4. **Frontend**:
   - Современный React интерфейс
   - Интеграция с backend API
   - Загрузка и предварительный просмотр файлов
   - Отображение прогресса задач
   - Адаптивный дизайн

5. **Тестирование**:
   - Unit тесты для всех сервисов
   - Интеграционные тесты
   - Тесты конфигурации
   - Тесты API эндпоинтов

### ⚠️ Частично реализовано:

1. **D-ID API с локальными файлами**:
   - ✅ Аутентификация работает
   - ✅ Получение списка talks работает
   - ❌ Создание talks с локальными URL не работает (требуются публичные URL)

### ❌ Требует реализации:

1. **Облачное хранилище файлов**:
   - Загрузка изображений в облачное хранилище (S3, Cloudinary, etc.)
   - Загрузка аудио файлов в облачное хранилище
   - Получение публичных URL для D-ID API

2. **Полный флоу генерации видео**:
   - Интеграция загрузки файлов в облачное хранилище
   - Использование публичных URL в D-ID API
   - Получение и отображение готовых видео
