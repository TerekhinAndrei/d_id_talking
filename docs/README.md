## 📖 Как использовать документацию

### Для разработчиков
1. Начните с [архитектурной документации](architecture/) для понимания структуры
2. Изучите [техническую документацию](technical/) для деталей реализации
3. Обратитесь к [интеграционной документации](integration/) для понимания интеграций

### Для новых участников
1. Прочитайте [README проекта](../README.md) для общего понимания
2. Изучите [архитектурные отчеты](architecture/) для понимания архитектуры
3. Ознакомьтесь с [техническими руководствами](technical/) для деталей

### Для менеджеров
1. Изучите [финальные отчеты](architecture/FINAL_PROJECT_AUDIT_SUMMARY.md) для понимания качества
2. Ознакомьтесь с [статусом интеграции](integration/FINAL_INTEGRATION_STATUS.md) для понимания прогресса
3. Просмотрите [технические детали](technical/TECHNICAL_DETAILS.md) для понимания возможностей
