## Архитектурные принципы

### SOLID принципы

1. **Single Responsibility**: `DIdFileService` отвечает только за файловые операции D-ID
2. **Open/Closed**: Расширяемость через интерфейсы
3. **Liskov Substitution**: Реализация `IDIdFileService`
4. **Interface Segregation**: Специфичные интерфейсы для файлов
5. **Dependency Inversion**: Зависимость от абстракций

### ООП принципы

- **Инкапсуляция**: Приватные методы валидации
- **Наследование**: Наследование от `BaseService`
- **Полиморфизм**: Использование интерфейсов
