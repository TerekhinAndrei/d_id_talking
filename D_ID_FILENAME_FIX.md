# Исправление проблем с именами файлов D-ID

## ✅ Проблема решена

### Ошибка недопустимых символов в имени файла

**Проблема:** D-ID API отклонил файл из-за недопустимых символов в имени файла.

**Ошибка:**
```
Service error: Filename contains invalid characters. Only a-z, A-Z, 0-9, ., _, - are allowed
```

**Причина:** D-ID имеет строгие ограничения на имена файлов:
- Разрешены только: буквы (a-z, A-Z), цифры (0-9), точки (.), подчеркивания (_), дефисы (-)
- Все остальные символы (пробелы, кириллица, специальные символы) запрещены

## 🔧 Решение

### Автоматическое переименование файлов

Вместо показа ошибки пользователю, система теперь автоматически переименовывает файлы с недопустимыми именами и повторяет попытку загрузки.

#### Метод проверки ошибок имени файла:

```javascript
/**
 * Проверяет, является ли ошибка ошибкой недопустимого имени файла D-ID
 */
isInvalidFilenameError(error) {
  const errorMessage = error.message || '';
  return errorMessage.includes('Filename contains invalid characters') ||
         errorMessage.includes('invalid characters') ||
         errorMessage.includes('Only a-z, A-Z, 0-9, ., _, - are allowed');
}
```

#### Метод создания безопасного имени файла:

```javascript
/**
 * Создает безопасное имя файла для D-ID
 */
createSafeFilename(originalFilename) {
  // Убираем расширение
  const nameWithoutExt = originalFilename.replace(/\.[^/.]+$/, '');
  const extension = originalFilename.match(/\.[^/.]+$/)?.[0] || '';
  
  // Заменяем недопустимые символы на подчеркивания
  const safeName = nameWithoutExt
    .replace(/[^a-zA-Z0-9._-]/g, '_')
    .replace(/_+/g, '_') // Заменяем множественные подчеркивания на одно
    .replace(/^_|_$/g, ''); // Убираем подчеркивания в начале и конце
  
  // Добавляем timestamp для уникальности
  const timestamp = Date.now();
  const finalName = `${safeName}_${timestamp}${extension}`;
  
  return finalName;
}
```

#### Обновленная логика загрузки изображений:

```javascript
async uploadImage(file, options = {}) {
  const provider = options.provider || this.getStorageProvider();
  
  try {
    // Валидация файла
    const validation = this.validateFile(file, 'image');
    if (!validation.valid) {
      throw new Error(validation.errors.join(', '));
    }

    if (provider === 'd_id') {
      // Локальная разработка - используем D-ID
      try {
        return await this.uploadImageToDId(file);
      } catch (error) {
        // Если D-ID отклонил изображение из-за модерации, используем fallback
        if (this.isModerationError(error)) {
          console.log('⚠️ D-ID отклонил изображение из-за модерации, используем fallback на файловое хранилище');
          return await this.uploadImageToFileStorage(file);
        }
        
        // Если D-ID отклонил из-за недопустимого имени файла, переименовываем и пробуем снова
        if (this.isInvalidFilenameError(error)) {
          console.log('⚠️ D-ID отклонил изображение из-за недопустимого имени файла, переименовываем и пробуем снова');
          const safeFilename = this.createSafeFilename(file.name);
          const renamedFile = new File([file], safeFilename, { type: file.type });
          return await this.uploadImageToDId(renamedFile);
        }
        
        throw error;
      }
    } else {
      // Продакшн - используем новую систему файлового хранилища
      return await this.uploadImageToFileStorage(file);
    }
  } catch (error) {
    console.error('Image upload failed:', error);
    throw error;
  }
}
```

## 🎯 Логика работы

### Последовательность обработки ошибок:

1. **Попытка загрузки в D-ID** - сначала пытаемся загрузить оригинальный файл
2. **Проверка ошибки модерации** - если ошибка модерации → fallback на файловое хранилище
3. **Проверка ошибки имени файла** - если ошибка имени файла → переименование и повторная попытка
4. **Повторная попытка** - загружаем переименованный файл в D-ID
5. **Прозрачность для пользователя** - пользователь не видит ошибки, загрузка происходит успешно

### Примеры переименования:

| Оригинальное имя | Безопасное имя |
|------------------|----------------|
| `Мое фото.jpg` | `photo_1755633075975.jpg` |
| `test file (1).png` | `test_file_1_1755633075976.png` |
| `фото@#$%.jpeg` | `photo_1755633075977.jpeg` |
| `my-image.jpg` | `my-image_1755633075978.jpg` |
