## 🔧 Технические детали

### Валидаторы
Все валидаторы используют `mode="after"` для преобразования строк в нужные типы:

```python
@field_validator("ALLOWED_HOSTS", mode="after")
@classmethod
def assemble_cors_origins(cls, v: str) -> List[str]:
    if v.strip() == "":
        return ["http://localhost:3000", ...]
    return [i.strip() for i in v.split(",")]
```

### Обработка ошибок
- Пустые строки заменяются значениями по умолчанию
- Невалидный JSON в FALLBACK_VOICES заменяется дефолтными голосами
- Все валидаторы имеют fallback значения
