# 🚀 Настройка и запуск фронтенда

## Быстрый старт

### 1. Установка зависимостей
```bash
cd frontend
npm install
```

### 2. Настройка переменных окружения
Создайте файл `frontend/.env`:
```bash
VITE_API_BASE_URL=http://localhost:8000
VITE_API_TIMEOUT=30000
```

### 3. Запуск в режиме разработки
```bash
npm run dev
```

Фронтенд будет доступен по адресу: http://localhost:5173

- Автоматическая загрузка списка голосов ElevenLabs

### 🎬 Генерация видео
- Отправка файлов на бэкенд
- Отслеживание прогресса в реальном времени
- Отображение D-ID Talk ID

### 📊 Отслеживание статуса
- Автоматический опрос каждые 2 секунды
- Прогресс-бар с анимацией
- Детальная информация о задаче
- Обработка ошибок

## API интеграция

### Эндпоинты:
- `GET /api/v1/health` - проверка здоровья API
- `GET /api/v1/voices` - получение списка голосов
- `POST /api/v1/generate` - создание задачи генерации
- `GET /api/v1/status/{task_id}` - получение статуса задачи

## Устранение неполадок

### Проблема: "Failed to connect to API"
**Решение:**
1. Убедитесь, что бэкенд запущен на порту 8000
2. Проверьте переменную `VITE_API_BASE_URL` в `.env`
3. Проверьте CORS настройки бэкенда

### Проблема: "No voices available"
**Решение:**
1. Проверьте API ключ ElevenLabs в бэкенде
2. Убедитесь, что эндпоинт `/api/v1/voices` работает

### Проблема: Файлы не загружаются
**Решение:**
1. Проверьте размер файлов (рекомендуется < 10MB)
2. Убедитесь, что формат файла поддерживается
3. Проверьте права доступа к файлам
