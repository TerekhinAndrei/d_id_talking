## Технические детали

### Используемые технологии:
- **Jest** - тестовый фреймворк
- **React Testing Library** - тестирование компонентов
- **@testing-library/jest-dom** - дополнительные матчеры
- **jsdom** - DOM окружение для тестов

### Конфигурация:
```javascript
// jest.config.js
export default {
  testEnvironment: 'jsdom',
  setupFilesAfterEnv: ['<rootDir>/src/setupTests.js'],
  moduleNameMapper: {
    '\\.(css|less|scss|sass)$': 'identity-obj-proxy',
    '\\.(jpg|jpeg|png|gif|eot|otf|webp|svg|ttf|woff|woff2|mp4|webm|wav|mp3|m4a|aac|oga)$':
      '<rootDir>/__mocks__/fileMock.js',
  }
}
```

## Найденные проблемы и их решения

### 1. Поиск элементов по тексту
**Проблема:** Тесты не находили кнопку по тексту "прослушать пример голоса"
**Решение:** Использование поиска по эмодзи "🔊" и "⏳"

### 2. Структура текста
**Проблема:** Текст "Выбран: Rachel" разбит на несколько элементов
**Решение:** Поиск отдельных частей текста

### 3. Mock компонентов
**Проблема:** ErrorMessage компонент не был замокан
**Решение:** Создание mock компонента с data-testid
