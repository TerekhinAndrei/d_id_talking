## 🔧 Исправленные проблемы

### 1. Проблема с .env файлом
**Проблема:** 
```bash
.env: line 25: голос,: command not found
```

**Причина:** Bash пытался выполнить комментарии на русском языке как команды

**Решение:** 
```bash
# Было:
source .env

# Стало:
D_ID_API_KEY=$(grep '^D_ID_API_KEY=' .env | cut -d'=' -f2-)
ELEVENLABS_API_KEY=$(grep '^ELEVENLABS_API_KEY=' .env | cut -d'=' -f2-)
```

### 2. Безопасная загрузка переменных
**Проблема:** Сложные значения в .env файле с пробелами и специальными символами

**Решение:** Избирательная загрузка только нужных переменных через grep
