# Интеграция новой системы файлового хранилища во фронтенд

## Обзор

Интегрирована новая система файлового хранилища во фронтенд с автоматическим переключением между D-ID (локально) и файловым хранилищем (на Render).

## Архитектура

### 1. Новый сервис файлов (`frontend/src/services/NewFileService.js`)

Основной сервис для работы с файлами:

- **Автоматическое определение провайдера**: D-ID для локальной разработки, файловое хранилище для продакшена
- **Единый интерфейс**: Совместимый API для загрузки изображений и аудио
- **Валидация файлов**: Проверка типов и размеров
- **Управление аватаром**: Получение информации о текущем аватаре

### 2. Обновленный FileService (`frontend/src/services/FileService.js`)

Адаптер для совместимости с существующим кодом:

- **Делегирование**: Все методы делегируют выполнение в NewFileService
- **Совместимость**: Сохраняет существующий API для компонентов
- **Прозрачность**: Компоненты не требуют изменений

### 3. Обновленный компонент ImageUpload (`frontend/src/components/ImageUpload.jsx`)

Расширенная функциональность:

- **Автозагрузка аватара**: При монтировании загружает информацию о текущем аватаре
- **Обновление информации**: После загрузки нового изображения обновляет информацию
- **Отображение статуса**: Показывает информацию о текущем аватаре

### 4. Новый тестер FileStorageTester (`frontend/src/components/FileStorageTester.jsx`)

Компонент для тестирования системы:

- **Тестирование подключения**: Проверка доступности сервисов
- **Загрузка файлов**: Тестирование загрузки изображений и аудио
- **Валидация**: Проверка валидации файлов
- **Информация о провайдерах**: Отображение настроек

## Функциональность

### Автоматическое переключение провайдеров

```javascript
// Локальная разработка
if (isDevelopment) {
  return 'd_id'; // Используем D-ID
} else {
  return 'file_storage'; // Используем файловое хранилище
}
```

### Загрузка изображений

```javascript
// Единый API для всех окружений
const result = await fileService.uploadImage(file);

// Результат содержит информацию о провайдере
console.log('Provider:', result.provider); // 'd_id' или 'file_storage'
console.log('URL:', result.data.url);
```

### Загрузка аудио

```javascript
// Аудио файлы автоматически удаляются через 10 секунд на продакшене
const result = await fileService.uploadAudio(file);

if (result.provider === 'file_storage') {
  console.log('Аудио будет автоматически удалено через 10 секунд');
}
```

### Получение информации об аватаре

```javascript
// Получение информации о текущем аватаре
const avatarInfo = await fileService.getCurrentAvatar();

if (avatarInfo && avatarInfo.success) {
  console.log('Текущий аватар:', avatarInfo.data.filename);
  console.log('URL:', avatarInfo.data.url);
}
```

## Тестирование

### FileStorageTester

Новый компонент для тестирования:

1. **Подключение**: Проверка доступности бэкенда
2. **Провайдеры**: Информация о доступных провайдерах
3. **Аватар**: Получение и отображение текущего аватара
4. **Загрузка**: Тестирование загрузки файлов
5. **Валидация**: Проверка валидации файлов

### Доступ к тестеру

В главном приложении добавлена кнопка "File Storage Тестер" в панели тестирования.

## Безопасность

### Валидация файлов

- **Типы файлов**: Проверка MIME-типов
- **Размер файлов**: Ограничение максимального размера
- **Расширения**: Проверка допустимых расширений

### Автоматическая очистка

- **Аудио файлы**: Автоматическое удаление через 10 секунд
- **Временные файлы**: Предотвращение накопления

### Локальная разработка

1. Запустите бэкенд: `./scripts/start-backend.sh`

3. Система автоматически использует D-ID

1. Настройте переменные окружения в Render
2. Деплой автоматически использует файловое хранилище
3. Аудио файлы автоматически удаляются
