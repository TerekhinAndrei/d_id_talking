## 🔧 Архитектура

### Бэкенд
```
FileStorageService
├── upload_image() - загрузка изображения (заменяет аватар)
├── upload_audio() - загрузка аудио (автоудаление через 10с)
├── get_current_avatar() - получение информации об аватаре
├── delete_file() - удаление файлов
└── validate_file() - валидация файлов

API Endpoints
├── POST /api/v1/files/upload/image
├── POST /api/v1/files/upload/audio
├── GET /api/v1/files/avatar
├── GET /api/v1/files/serve/{file_path}
└── DELETE /api/v1/files/files/{file_id}
```

### Фронтенд
```
NewFileService (основной сервис)
├── getStorageProvider() - определение провайдера
├── uploadImage() - загрузка изображений
├── uploadAudio() - загрузка аудио
└── getCurrentAvatar() - получение аватара

FileService (адаптер)
└── Делегирует все методы в NewFileService

ImageUpload (обновленный компонент)
├── Автозагрузка информации об аватаре
├── Обновление после загрузки
└── Отображение статуса
```

## 🌍 Окружения

### Локальная разработка
- **Провайдер**: D-ID
- **URL**: `http://localhost:8000`
- **Функции**: Полная функциональность D-ID

### Продакшн (Render)
- **Провайдер**: Файловое хранилище
- **URL**: `https://talking-head.onrender.com`
- **Функции**: Автоматическая очистка аудио, публичные URL

## 📁 Структура файлов

```
uploads/
├── avatar/
│   ├── default_avatar.jpg  # Резервный аватар
│   └── avatar.png         # Текущий аватар
└── audio/
    └── {uuid}.wav         # Временные аудио файлы
```

## 🔒 Безопасность

- **Валидация файлов**: Проверка MIME-типов и размеров
- **Защита от обхода директорий**: Проверка путей файлов
- **Автоматическая очистка**: Предотвращение накопления временных файлов
- **Ограничения размера**: Максимум 10MB для файлов
